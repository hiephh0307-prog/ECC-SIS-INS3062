1. CẤU TRÚC THƯ MỤC BÀI LÀM
------------------------------------------------------------------------
  - run.bat                 : Bấm đúp 1 chạm để tự mở Web ECC-SIS trên máy Windows
  - HUONG-DAN-MO-WEB.txt    : Tệp hướng dẫn này
  - demo_deliverables/      : Video thuyết trình Demo MP4 (3m45s), phụ đề .srt,
                              Kịch bản demo & Q&A, file PDF mẫu, 8 ảnh màn hình
  - docs/                   : Báo cáo chi tiết, Khung phân công, Technical Report
  - ecc_core/               : Lõi mật mã ECC tự lập trình bằng Python thuần
  - benchmarks/             : Bộ đo tốc độ Affine vs Jacobian & ECC vs RSA-3072
  - sis_app/                : Backend FastAPI + SQLite + Web UI WebCrypto P-256
  - tests/                  : 13 kiểm thử tự động chuẩn NIST CAVP & API
  - Dockerfile / render.yaml: Cấu hình đưa web lên mạng chạy 24/7 miễn phí

2. CÁCH 1 — MỞ WEB TRÊN MÁY CÁ NHÂN (NHANH NHẤT, 1 CHẠM)
------------------------------------------------------------------------
  - Bước 1: Giải nén toàn bộ file .zip ra một thư mục (không chạy trực tiếp
            bên trong cửa sổ xem trước zip).
  - Bước 2: Bấm đúp chuột vào file `run.bat`.
            Script tự kiểm tra Python, tự cài fastapi/uvicorn (nếu thiếu),
            khởi chạy máy chủ nội bộ tại http://127.0.0.1:8000 và tự mở trình duyệt.
  (Lưu ý: nếu Windows lần đầu chưa có Python, script sẽ tự gọi winget cài
   Python 3.12 hoặc báo link cài đặt 1 phút từ python.org).
